# Applywise

Applywise is a small, local-first job application assistant. It helps you keep your opportunities, follow-ups, and role notes together without requiring an account or a server.

## Run it

Open `index.html` in a current desktop or mobile browser. The app has no build step or package dependencies.

## What’s included

- Track a role’s company, title, location, work style, date applied, status, follow-up date, salary range, job link, job description, and personal notes.
- Update or delete applications; search by company, role, or location and filter by status.
- See pipeline counts, interview totals, upcoming follow-ups, and recent applications on the overview.
- Add skills to your profile and compare them against saved job descriptions. The fit signal is the percentage of your listed skills found as phrases in a description; the Insights view shows role-by-role alignment and your top match.
- Keep application and skill data in this browser’s `localStorage`. Data does not sync across devices or get sent to a server.

The fit signal is a basic keyword comparison, not an assessment of qualifications or a prediction of hiring outcomes. No data is preloaded, so the dashboard starts with a clean slate.
