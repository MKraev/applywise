# Using Applywise

## Start the app

Open `index.html` in a current browser. No installation, account, or build step is required. Applywise starts with an empty workspace.

## Add an application

Select **Add application** from the overview or applications screen. Company and role title are required. The form also accepts:

| Field | What it’s for |
| --- | --- |
| Location | City, region, or remote location details |
| Work style | Remote, hybrid, or on-site |
| Date applied | Defaults to today; can be changed |
| Current status | Where the opportunity is in your search |
| Next follow-up | A date to keep on your radar |
| Salary range | The range or compensation details you want to remember |
| Job description | The role text used for your fit signal |
| Your notes | Interview details, contacts, questions, or other private reminders |
| Job link | An optional `http` or `https` link to the posting |

Select **Save application** to add it. Select an application row later to reopen its details, update it, or delete it. Deleting requires confirmation and cannot be undone within the app.

## Track status and follow-ups

Available statuses are **Applied**, **Screening**, **Interview**, **Offer**, and **Rejected**. Rejected applications appear as closed in the pipeline. They are excluded from the active-application and follow-up counts.

The overview’s **Up next** list includes non-rejected applications whose follow-up date is overdue or within the next seven days. It is a visual reminder inside the app, not a notification or calendar event.

## Find an application

Open **Applications** to see the full list. Search matches company, role title, and location. The status selector narrows the list to one status. Select a row to edit it; use the ↗ action when a saved job link is available.

## Add your strengths and view fit insights

Choose **Edit skills** from the profile card or avatar. Enter skills separated by commas, semicolons, or new lines, then save. Applywise keeps up to 30 unique entries, each up to 45 characters.

Add a job description to an application. The form shows a preview when you have skills in your profile. **Fit insights** compares the saved descriptions and displays the role-by-role results and highest-scoring role.

The fit signal only checks whether each saved skill phrase appears in the description. It does not evaluate context, experience level, synonyms, or the quality of your application; use it as a prompt for reflection, not as a hiring prediction.
