# Applywise documentation

Applywise is a browser-based job application tracker with a lightweight role-fit signal. This folder explains how to use it and how its data and features work.

## Guides

- [Using Applywise](./using-applywise.md) — add and update applications, manage follow-ups, search your list, and use the skills profile.
- [Features and workflow](./features-and-workflow.md) — what each screen shows and how the fit signal is calculated.
- [Data and privacy](./data-and-privacy.md) — where information is stored, what is sent externally, and how to clear saved data.
- [Project structure](./project-structure.md) — the purpose of the app files and how to run the project.

## Important limitation

Applywise currently runs entirely in the browser. There is no account, server, cloud sync, automatic email/calendar integration, or built-in export/import. Treat browser-local data as personal and keep your own backup if you need one.
