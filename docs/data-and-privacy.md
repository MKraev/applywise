# Data and privacy

## Where data is stored

Applications and skills are saved in the browser’s `localStorage` for the current site origin:

- `applywise.applications.v1` stores application records.
- `applywise.skills.v1` stores the skills profile.

The app does not have a server, sign-in, or cloud backup. Data is not synchronized to another browser, device, or origin. Clearing site data or browser storage can remove it. Private/incognito windows may discard it when closed. Avoid relying on this browser storage as your only record of important application details.

Changes to the same Applywise storage in another tab are reflected in the open page. This is local browser behavior, not cross-device synchronization.

## Network behavior

Application and skill data are not uploaded by Applywise. If you add a job link and open it, that destination may receive the request under its own privacy policy. The page also references Google Fonts for typography; if the fonts cannot load, the browser uses fallback fonts.

## Clear saved data

To remove Applywise data, clear this site’s browser storage/local storage using the browser’s site-data or developer tools. This also removes all applications and skills saved for this origin. There is currently no in-app reset or export/import control.

## Fit signal and personal decisions

The fit score is a local keyword comparison, not a judgment about your qualifications or a prediction of hiring outcomes. Review opportunities using your own experience and judgment.
